Solana · pump.fun · Claude

JopTrades AI Trader

An autonomous pump.fun trading bot where Claude — running through your own Claude Code subscription — is the analyst deciding what to buy.

@solana/web3.js PumpPortal Claude Agent SDK Node.js

How it works

1
Listen A PumpPortal websocket streams every new pump.fun token launch in real time.
2
Analyze Each launch is sent to Claude (via a local proxy on the Claude Agent SDK — auth is your Claude Code login). Claude returns a BUY/HOLD call with a confidence and risk score.
3
Execute On a high-confidence BUY, the bot builds the trade via PumpPortal, signs it with your wallet, and broadcasts it through your own Solana RPC.
4
Manage Held positions are watched on the trade stream and closed on take-profit or stop-loss.

Built-in guardrails

Hard caps
Max position size, max open positions, and a max daily spend — enforced on every buy no matter what Claude says.
Dry-run default
Ships analyzing real launches but sending nothing on-chain until you explicitly opt in.
Live-trading guard
Real trades require two separate env flags set on purpose — deliberate friction.
Kill switch
One flag halts all buying instantly while analysis keeps running.

Run it

git clone https://github.com/JustLinkIt1/joptrades-solana-pumpfun
cd joptrades-solana-pumpfun
npm install
cp .env.example .env      # add a burner wallet key + an RPC url

npm run proxy             # terminal 1 — Claude Code proxy
npm run bot               # terminal 2 — the trader (dry-run by default)

The bot is a server-side Node process — it runs on your machine or a VPS, not on this page. This site is just the overview.

⚠ Risk

pump.fun launch-sniping is one of the highest-variance activities in crypto. Most tokens go to zero, and many are rug pulls or bundled snipes. The caps and guards limit how fast a bad run — or a bug — can drain a wallet; they do not make this safe. Use a dedicated burner wallet, size small, and treat the entire balance as at-risk. This is not financial advice.
